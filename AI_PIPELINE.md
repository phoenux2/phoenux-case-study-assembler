# AI Pipeline

Goal

Use as few tokens as possible.

---

## Pipeline

```
Deterministic Parsing

↓

Structured Facts

↓

Gap Detection

↓

Questions

↓

Editorial Writing
```

---

## AI Tasks

Extraction

Gap Detection

Question Refinement

Claim Review

Editorial Polish

---

Do NOT use AI for

Layouts

Templates

Metadata

Permissions

Sorting

Database Logic

Coverage

Assembly

---

Prompt Rule

Every prompt

- one task
- one schema
- one output

Never one huge prompt.
