# Question Engine

Questions are adaptive.

Never display a giant form.

## Flow

```
Coverage Check

↓

Missing Information

↓

Question Selection

↓

Answer

↓

Update Database

↓

Coverage Check
```

## Supported Questions

Boolean

Single Select

Multiple Select

Short Text

Long Text

Number

Asset Selection

Text + Image

Before / After

Confidence

Permission

---

Questions should always explain WHY they are being asked.

Example

"I found onboarding screens but I don't know what problem they solved."

---

Many questions require images.

Example

Question

"What problem did this solve?"

↓

Attach Image

↓

Highlight Area

↓

Explain Change

↓

Attach Final Image
