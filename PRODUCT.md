# Product Overview

## Problem

Old projects contain scattered information.

- screenshots
- proposals
- Figma exports
- emails
- meeting notes
- memories

Nobody remembers enough to manually write a proper case study.

## Solution

The application reconstructs projects.

It should

- collect evidence
- ask questions
- pair answers with images
- assemble reusable blocks
- generate final outputs

The application is **not** an AI writer.

It is a structured project reconstruction system.

## Success

A user can create

- Website Case Study
- LinkedIn Carousel
- LinkedIn Post
- Upwork Portfolio

from one structured project.

## Principle

Generate little.

Assemble everything.
