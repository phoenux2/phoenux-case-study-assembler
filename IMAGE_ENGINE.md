# Image Engine

Every uploaded image becomes an Asset.

Assets are reusable.

Do not duplicate them.

## Metadata

```
Title

Category

Phase

Permission

Description

Caption

Relationships

Quality

Confidence
```

An image can support multiple answers.

Example

Dashboard

↓

Problem

↓

Solution

↓

Design System

↓

Outcome

The system should only run Vision when required.

Never process every uploaded image.
